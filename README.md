# Справочник команд Ubuntu 24

Офлайновый справочник команд Ubuntu 24 на русском языке. Один файл на Python + tkinter, только стандартная библиотека — интернет не нужен, устанавливать ничего не нужно.

## Что внутри

- **Команды** — 70 команд в 13 категориях (файлы, каталоги, навигация, права, пакеты, система, процессы, диски, сеть, логи, поиск, архивы, пользователи). У каждой — понятное объяснение и 3–5 неочевидных примеров с разбором флагов. Опасные команды помечены предупреждением ⚠.
- **Основы** — 14 базовых тем про работу в терминале (перенаправления, конвейеры, подстановки и т. д.).
- **Ошибки** — 12 частых ошибок с причинами и способами исправления.

## Как запустить

- **Windows 10** — двойной клик по файлу `app.py`.
- **Linux / WSL** — `python3 app.py`.

Нужен Python 3 с tkinter (в обычном Python для Windows он уже встроен). Зависимостей нет, файл один.

## Как искать

Просто печатайте по-русски: «создать папку», «удалить файл», «посмотреть логи», «сжать папку в архив». Понимает слова в разных формах («созд» найдёт `mkdir`). Чем длиннее фраза, тем точнее результат: каждое слово сужает поиск.

## Для кого

Для новичка в Linux, которому нужно быстро вспомнить команду и понять, что она делает, — без гугла и без учебника.
